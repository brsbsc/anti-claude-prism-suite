# 主备多账号协作与槽位交接规则模板（Anti-Claude Prism Suite · 通用开源版）

> 将本规则放入你的用户或项目规则中，即可配合 `prism_memory_*`（或你本机已安装的 `memory` MCP）在多个 Antigravity 账号间无感续写任务，同时 100% 保留本地会话历史与工作区目录。

## 1. 主号 / 备用号分工习惯

- **主账号（Primary）**：日常主力开发账号；额度低于阈值或需换脑复核时再启用备用号，主号恢复后优先切回主号。
- **备用账号（Backup）**：额度兜底与长链路接力账号；与主账号**共用同一套本地项目工作区与对话历史**（不复制仓库）。
- **5h 窗口（≤ 10%）优先换模型家族，7d 窗口（≤ 5%）再切账号**：
  - 同一账号内若仅某个模型家族（如 Claude / Gemini）受限，可先切另一个独立模型家族继续；
  - 只有当核心模型或 7d 总额度见底时，才通过 Prism 工作台「账号接力」或 `npm run accounts -- switch <id>` 切换凭据槽。

## 2. 切号前自动落盘 4 要素交接记忆

每次切号前，记录并保留以下 4 要素（已自动对密钥/Token 脱敏，绝不存入明文凭据）：

1. **槽位标识与时间**：`handoff:<project>:<slot>`
2. **实际工作目录**：主目录或具体 worktree 路径
3. **Git 状态摘要**：当前分支、最新 commit SHA 及未提交文件数
4. **已验证进度与下一步动作**：可直接落地的下一条命令或目标

工具选择：
- **未安装外部 `memory-mcp`**：使用内置零依赖工具 `prism_memory_store` / `prism_memory_list` / `prism_memory_search`。
- **已安装外部 `memory-mcp`**：Prism 工作台可一键复制标准化 `memory_store` 指令实现双端同步。

## 3. 切号后极速续接（防陈旧记忆覆盖）

当你切回账号、重载 Antigravity 后发送 `接力` 或 `接力 [<槽位>]` 时：

1. **按时间倒序精确拉取最新进度**：优先调用 `prism_memory_list`（按 `project` / `slot` 精确筛选并严格按时间戳倒序取最新 1–2 条），不要只依赖语义相似度检索，避免旧里程碑排在前面误导方向。
2. **只读核对本地现场**：对照检查项目 `git status` 与交接目录是否一致。
3. **先报 3 行回执再动手**：
   `已对齐 [<槽位>]（来自 <时间> 交接）｜工作目录：<路径>｜上次进度：<摘要>｜现在继续：<动作>`
